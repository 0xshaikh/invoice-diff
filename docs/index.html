Features

Three stages. One command.

Each stage is a pure function of files in and files out. Wire them together in shell, or run the whole pipeline with one reconcile.

📥

Parser

Reads marketplace-specific invoice formats, normalises currency, splits line items, and tags each row with its source marketplace and order id.

Flipkart Meesho Amazon.in CSV / XLSX / JSON
⚖️

Reconciler

Matches invoices against payouts and classifies every gap into one of seven discrepancy types — each with a rupee impact and a severity.

gst value missing + 4 more
📤

Exporter

Writes the full report — typed, priced, sorted — to the format your accountant, auditor or CI pipeline wants. All four at once if you like.

JSON CSV Markdown XLSX

Install in 60 seconds

From nothing to a report in a minute.

~/work/finance — zsh 
# 1. requires Python 3.10+
pip install invoice-diff

# 2. point it at your invoices
invoice-diff init

# 3. reconcile and export
invoice-diff reconcile --marketplace all --in invoices/ --out report.xlsx
  1. Install from PyPI with pip install invoice-diff — or straight from GitHub if you prefer.
  2. Drop marketplace exports and your bank statement into invoices/. Filenames don't need to match anything.
  3. Run reconcile. The command is idempotent — rerun it on new data without touching state.
  4. Read report.xlsx. Hand it to your accountant. Move on with your month.
FAQ

Questions, answered.

Does invoice-diff log in to my marketplace accounts?

No. It never touches the internet. You download the CSV/XLSX exports yourself from each marketplace dashboard, and invoice-diff reads those files. Your credentials never leave your machine and your data never leaves your disk.

Which marketplaces are supported?

Flipkart, Meesho and Amazon.in — the three that cover the bulk of Indian seller payouts today. The parser layer is pluggable, so a fourth marketplace is a parser module plus a rate table, not a fork.

What counts as a "discrepancy"?

Any mismatch between an invoice line and its corresponding payout — classified into one of seven types: gst, value, missing, duplicate, late, rounding and unmatched. Each carries a rupee impact and a severity.

Is my data sent anywhere?

No. There is no telemetry, no analytics, no phone-home. Every stage reads from local files and writes to local files. The whole run is reproducible offline.
